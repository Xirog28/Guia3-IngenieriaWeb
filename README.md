# 🌿 Portafolio Personal — Guía 3 Ingeniería Web I

## 📌 Descripción

Este proyecto corresponde a la Guía de Laboratorio 3 de la asignatura
Ingeniería Web I.

Se desarrolló un sitio web de una sola página (Single Page) utilizando
HTML5 semántico y CSS3 con diseño responsive mediante Flexbox.

El sitio está compuesto por tres secciones principales:

- Inicio
- Sobre mí
- Contacto

Además, cuenta con navegación mediante anclas internas y un formulario
de contacto accesible.

---

# 🎯 Objetivo del proyecto

Construir un sitio web completo que integre los conocimientos de HTML5
semántico, CSS3, Flexbox, diseño responsive y accesibilidad.

El proyecto busca demostrar la capacidad de organizar correctamente
el contenido de una página web y adaptarlo a diferentes tamaños de
pantalla.

---

# 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Git
- GitHub
- Visual Studio Code
- Navegador web
